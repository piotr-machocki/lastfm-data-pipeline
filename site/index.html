About the Project

This project demonstrates an automated data engineering pipeline for processing Last.fm scrobble data and generating listening analytics.

The pipeline extracts data from the Last.fm API, transforms and validates the records, and loads them into PostgreSQL for analysis.

GitHub Actions automates data ingestion and dashboard updates, while the processed data is presented here through GitHub Pages.
